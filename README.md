# Portal for computers — downloads

Installers for **Portal**, the app that lets your phone reach this computer's folders.
Get the latest version from [Releases](https://github.com/Billst3b/portal-releases/releases/latest) or from [sendviaportal.com/download](https://sendviaportal.com/download).

- **Windows:** `Portal-Setup-<version>.exe`
- **Fedora / RHEL:** `Portal-<version>.x86_64.rpm`
- **Ubuntu / Debian:** `Portal-<version>.amd64.deb`
- **Other Linux:** `Portal-<version>.x86_64.AppImage`

This repository holds only the installers; it contains no source code.
